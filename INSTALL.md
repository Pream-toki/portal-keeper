# Install

## Windows

1. Unzip the folder somewhere permanent — not the Downloads pile.
2. Double-click `portal-keeper.exe`. A circle appears in the tray (hidden icons `^`).
3. Right-click it → **Open config (accounts)**. For each Wi-Fi put the name, your username and
   your password. Save.
4. That's it. It starts with Windows by default; untick **Start with Windows** in the menu if you
   don't want that.

Green = signed in, amber = retrying, grey = paused. **Test sign-in now** forces a check.

Wi-Fi names are matched loosely: `Campus.FL7`, `Campus-FL7` and `campus fl7` are the same
network. `keeper.log` appears in the folder only when a sign-in fails — the last lines say what
the portal answered.

## Android

1. Copy `PortalKeeper.apk` to the phone, open it, allow installing from this source.
2. Open Portal Keeper, allow Location and Notifications, check the two accounts, press
   **Save accounts**.
3. Press **Allow background (battery)**, then **Start / stop keeper**.
4. A quiet notification shows the state. It comes back by itself after a reboot.

Passwords stay on your own device, in the app's private storage or in `config.json`. Nothing is
uploaded anywhere.
